# 인기 검색과 수급 차트

사용자가 승인한 범위는 검색창 진입 시 인기 검색, 시장 외국인 현물·선물 수급 확대 차트, 국내 종목별 외국인·기관·개인 수급 차트다. OI와 API 키 연동은 추후 작업이다.

- 기존 Electron, JavaScript, Chart.js와 네이버·다음 데이터만 사용한다. 새 의존성과 IPC는 추가하지 않는다.
- 검색창이 비었으면 기존 국내 인기 검색 순위와 1분 캐시를 공유한다. 입력하면 일반 검색, 비우면 인기 검색으로 돌아온다. 늦은 응답이 현재 검색을 덮어쓰지 않는다.
- 시장 지표의 일별 외국인 현물·선물 줄과 장중 투자자별 수급 줄에서 확대 차트를 연다. 프로그램은 시계열이 없어 제외한다. 장중은 현물/선물을 전환한다.
- 종목 지표의 투자자별 순매수 표를 유지하고 최근 최대 20거래일의 세 주체를 함께 보는 차트 버튼을 추가한다.
- 확대 차트는 위젯 안 모달로 표시한다. 닫기/Esc 후 원래 화면과 포커스로 돌아오며, 배경의 종목·기간 단축키는 동작하지 않는다.
- 시장 수급은 억 원, 종목 수급은 주(KRX)다. 장중 잠정치와 일별 잠정치는 명시한다. 누락값은 0으로 만들지 않는다.
- 로딩·빈 데이터·조회 실패를 구분하고 재시도를 제공한다. 요청 중 닫거나 보기를 바꾼 경우 이전 응답을 표시하지 않는다.

## 접근 방식

기존 가격 차트에 수급을 함께 넣는 방법과 별도 확대 창을 비교했다. 단위·기간과 가격 차트 상태를 섞지 않는 별도 창으로 구현한다. 데이터 조회와 캐시는 기존 구현을 재사용한다. 월 단위의 장기 수급 이력 확장은 이번 범위에 포함하지 않는다.
