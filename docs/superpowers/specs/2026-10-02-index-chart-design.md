# 코스피 · 코스닥 지수 차트 — 설계

2026-10-02

## 왜

상단 지수 줄은 코스피 · 코스닥의 값과 등락률 한 줄뿐이다. 오늘 장이 어떻게 흘렀는지, 몇 달 동안 어디쯤인지는 볼 수 없다. 종목이 빠질 때 "시장 전체가 빠지는 건지"를 보려고 둔 줄인데, 흐름을 보려면 다른 프로그램을 열어야 한다.

## 사용자가 정한 것

| 질문 | 결정 |
|---|---|
| 지수를 누르면 상세 헤더는 | 지수 정보로 바꾼다 — 헤더와 차트가 늘 같은 대상 |
| 접힌 상태에서 누르면 | 종목 줄과 같게 선택만 바꾼다 (펼치지 않는다) |
| 구현 방식 | 지수도 "고를 수 있는 항목"으로 — 별도 보기 모드를 두지 않는다 |

## ① 선택과 화면

**상단 지수 줄**
- 코스피 · 코스닥을 각각 누를 수 있다. 마우스를 올리면 손가락 커서와 `title` "코스피 차트 보기".
- 보고 있는 지수는 관심종목 선택 줄(`.row.on`)과 같은 계열로 강조한다.

**고르기**
- 지수를 누르면 `select(지수 기호)` — 종목 줄을 누를 때와 같은 함수다. 목록 강조가 풀리고 헤더 · 차트가 지수로 바뀐다. 종목 줄을 누르면 돌아온다.
- 대상이 바뀌면 확대 구간을 모두 버린다(`clearZooms`, 지금 종목을 바꿀 때와 같다). 같은 지수를 다시 누르면 아무 일도 없다.
- 차트 기간(1D ~ 1Y)은 지금처럼 하나의 값이라 대상과 상관없이 유지된다.

**키보드**
- 지수를 보고 있을 때 `↓` 는 관심종목 첫 줄, `↑` 는 마지막 줄. (지금은 선택이 목록에 없으면 위아래 모두 첫 줄로 간다.)
- `1` ~ `5` 기간 키는 그대로.

**그 밖**
- 선택은 지금처럼 저장된다(`state.selected`). 껐다 켜도 보던 지수가 선택돼 있다.
- 접힌 상태(`.widget.compact`)에서 누르면 선택만 바뀐다. 접힌 상태는 `.detail` 만 숨기므로 펼치면 지수 차트가 보인다 — 지금 종목 줄과 같다.
- 관심종목이 비어 있어도 지수는 볼 수 있다.

## ② 데이터

| 무엇 | 출처 | 비고 |
|---|---|---|
| 현재값 · 전일 대비 · 등락률 · 오늘 시 · 고 · 저 · 장 상태 · 시세 시각 | 네이버 지수 실시간 `quote:indices` | 이미 30초마다 받는다. 지금은 값 · 등락률만 꺼낸다 |
| 차트 1D ~ 1Y · 거래량 | 야후 `^KS11` · `^KQ11` | 기존 `yf:chart` 그대로. 모든 기간 확인(2026-10-02) |
| RSI · 이동평균용 5년 일봉 · 52주 | 야후 일봉(`dailyFor`, 30분 캐시) | 종목과 같은 경로 |

야후 지수 분봉도 종목처럼 20분 늦다(15:23 에 마지막 5분봉 15:00, 2026-10-02 실측).

**흐름**
1. `main.js` `quote:indices` 가 항목마다 더 담는다: `code`(`KOSPI` · `KOSDAQ`), `change`, `open` · `high` · `low`, `isOpen`(`marketStatus === 'OPEN'`), `tradedAt`(`localTradedAt`). 새 요청은 없다.
   - 전일 대비는 종목처럼 부호 있는 값이다 — 2026-10-02 15:37 응답에서 하락한 코스닥이 `-1.00` 이었다.
   - 빠진 값(전일 대비 · 시 · 고 · 저)은 0 이 아니라 `null` 로 둔다. 0 이면 시가 0 캔들, 전일 대비 0 으로 잘못 그린다.
2. `renderer.js` 에 지수 목록을 둔다: `{ symbol: '^KS11', code: 'KOSPI', name: '코스피' }`, `{ symbol: '^KQ11', code: 'KOSDAQ', name: '코스닥' }`.
3. 네이버 지수 항목 → 종목 실시간 시세와 같은 모양으로 바꾸는 순수 함수(`indexLive`):
   `price`(값), `prevClose`(값 − 전일 대비), `candle`(시 · 고 · 저, 시가가 없거나 0 이하면 없음), `session` · `priceSession`(열려 있으면 `regular`, 아니면 `closed`), `isTrading` · `open`(열림 여부), `source: 'Naver'`, `tradedAt`.
   전일 대비가 없으면 실시간 값이 없는 것으로 친다(`undefined`) — 야후 값(20분지연)으로 넘어간다.
4. `refreshAll` 이 지수 줄을 그린 뒤 두 지수 모두 `loadQuote(지수, indexLive(…))` 로 `quotes['^KS11']` 등을 만든다. 그러면 RSI · 52주 · 이동평균 · 1D 끝점 이어 붙이기 · 일봉 마지막 봉 맞추기가 종목과 똑같이 동작한다. 야후 일봉은 30분 캐시라 늘어나는 요청은 30분에 2건이다.
5. `main.js` 의 기호 허용 패턴(`SYMBOL_RE`)이 맨 앞 한 글자 `^` 를 받도록 넓힌다. `^` 는 맨 앞에만, 한 번만.

**갱신 간격**: 지금처럼 관심종목의 장 상태로 정한다(`pollingIsOpen`). 지수는 넣지 않는다.

## ③ 헤더 · 차트

**종목과 같이 보이는 것**
- 헤더: 이름, 현재값, 전일 대비, 등락률, 오늘 캔들(네이버 지수 시 · 고 · 저), RSI 배지, 52주, 기간 수익률 배지.
- 상단 상태 표시(`renderUpdated`): 지수의 장 상태와 갱신 시각.
- 차트: 1D ~ 1Y, 이동평균, 골든/데드, 추세선, 캔들/라인, 확대, 거래량, 1D 전일 기준선. 1D 끝점은 실시간 지수값.
- 1D · 1W 분봉이 비었을 때의 안내(`intradayWaitText`)는 국내 종목처럼 "09:20쯤부터" 를 말한다. 지금은 `isDomestic` 으로 가르므로 지수도 이 쪽에 넣는다. `isDomestic` 자체는 바꾸지 않는다 — 폴링 · 알림이 쓴다.

**지수에서만 다른 것**
- 숫자는 소수 둘째 자리(6,995.86 · +24.51). 지수의 통화 자리에는 `'pt'`(포인트)를 쓴다 — `curOf` 가 지수 기호면 `'pt'` 를 돌려준다. `money` 는 원화가 아니면 소수 둘째 자리로 쓰므로 헤더 · 오늘 캔들 안내 · 52주 · 차트 축 · 툴팁이 저절로 맞는다.
- 이름 옆 통화 표시 `(USD)` 는 원화와 포인트일 때 붙이지 않는다.

**지수에서 빠지는 것**
- 업종: 지수면 조회하지 않는다.
- 보유 평가 줄 · 평단 점선 · 종가대비 줄 · 목표가 알림: 지수에는 값이 없어 저절로 빠진다(보유 · 목표가는 관심종목에만 입력할 수 있다).

## ④ 오류

- 네이버 지수를 못 받으면 지금처럼 지수 줄을 숨긴다. 지수를 보던 중이면 헤더는 야후 값으로 "20분지연" 을 붙여 계속 보인다(`loadQuote` 에 실시간 없이 들어간다 — 종목 폴백과 같다).
- 야후 지수 차트를 못 받으면 종목과 같다: 차트를 지우고 "코스피 차트: (오류)".
- 시작할 때 저장된 선택이 관심종목도 지수도 아니면 첫 관심종목(지금과 같다).
- 지수를 보던 중 종목을 지우거나 되돌려도 선택은 지수 그대로.

## 바꾸는 곳

**`main.js`**
- `quote:indices` 항목에 `code` · `change` · `open` · `high` · `low` · `isOpen` · `tradedAt`.
- `SYMBOL_RE` 가 맨 앞 `^` 하나를 허용.

**`renderer.js`**
- 지수 목록, `isIndex(symbol)`, `indexLive(n)`.
- 지금 선택된 대상을 돌려주는 `selectedItem()` — 관심종목에 있으면 그 항목, 지수면 지수 항목, 아니면 `null`. `renderDetail` · `loadChart` 의 `state.watchlist.find(… state.selected)` 를 이것으로.
- `loadIndices` 를 받기(네트워크)와 그리기(`renderIndices`, 강조 · 클릭)로 나눈다. `select()` 가 강조를 다시 그린다.
- `refreshAll`: 지수 시세 만들기.
- `curOf`: 지수면 `'pt'`. `renderDetail` 의 통화 표시 조건.
- `renderDetail`: 지수면 업종 조회를 건너뛴다.
- `moveSelection`: 선택이 목록에 없으면 `↓` 첫 줄, `↑` 마지막 줄.
- `intradayWaitText`: 지수도 국내처럼.
- 시작할 때 선택 검사: 지수 기호도 받아들인다.

**`index.html`**
- 지수 항목의 커서 · 강조 스타일.

## 테스트

사용자 지시: 문법 검사와 앱을 띄우지 않는 스위트까지. 앱을 띄운 확인은 사용자가 한다.

- `tests/session-ui.mjs`
  - `selectedItem`: 관심종목 · 지수 · 둘 다 아님
  - `indexLive`: 값 · 전일 종가 · 등락 · 캔들 · 장 상태, 시가가 없으면 캔들 없음, 전일 대비가 없으면 `undefined`
  - `curOf` / `money`: 지수 소수 둘째 자리, 종목은 지금 그대로
  - `moveSelection`: 지수에서 `↓` 첫 줄, `↑` 마지막 줄
  - 시작할 때 선택 검사가 지수 기호를 받아들인다 — 검사를 함수로 빼서 확인한다
  - `intradayWaitText`: 지수도 09:20 안내
- 새 스위트 `tests/index-main.mjs` — `main.js` 를 가짜 electron 으로 불러(`net-timeout` 과 같은 방식)
  - `yf:chart` 가 `^KS11` 은 받고 `^^KS11` · `KS11^` · `^` 는 거절한다
  - `quote:indices` 가 저장해 둔 네이버 지수 응답(새 픽스처)에서 새 필드를 꺼낸다. 빠진 값은 `null`
- CI 목록 · `tests/run.mjs` `ORDER` · 스위트 수(11 → 12) 문서에 반영.

## 하지 않는 것

- 종목 차트 위에 지수를 겹쳐 그리기(상대 강도 비교)
- 코스피 · 코스닥 외 지수(코스피200, 해외 지수)
- 지수 목표가 알림 · 지수 보유
- 지수를 관심종목 목록에 넣기
