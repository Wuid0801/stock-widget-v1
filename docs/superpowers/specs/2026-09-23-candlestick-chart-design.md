# 차트를 캔들로 — 1M · 3M

**날짜**: 2026-09-23
**상태**: 설계 승인됨, 구현 전

## 무엇을 만드나

일봉 차트(1M · 3M)를 종가 라인 대신 **캔들**로 그린다. 타임프레임 줄의 토글 버튼으로
라인과 오갈 수 있고, 선택은 저장된다.

시·고·저·종은 이미 다 들어와 있다. `main.js` 의 `yf:chart` 가 2026-09-22 부터
`opens` 를 함께 돌려주고(오늘 캔들 작업), `highs` · `lows` 는 고가~저가 밴드가
이미 쓰고 있다. **새로 받아올 데이터가 없다.**

## 범위

**1M · 3M 에서만** 캔들을 그린다. 창이 340px 라 차트 영역이 약 280px 인데,
타임프레임마다 봉 하나에 돌아가는 폭이 크게 다르다.

| 타임프레임 | 봉 수 | 봉 하나당 | 캔들 |
|---|---:|---:|---|
| 1D (5분봉) | ~73 | 3.8px | 안 그린다 — 분봉이라 "일봉 캔들"과 뜻이 다르다 |
| 1W (30분봉) | ~65 | 4.3px | 안 그린다 — 같은 이유 |
| 1M | ~22 | 12.7px | **그린다** |
| 3M | ~65 | 4.3px | **그린다** |
| 1Y | ~243 | 1.2px | 안 그린다 — 몸통도 꼬리도 구분되지 않는다 |

이동평균선이 "구간에 비해 너무 긴 기간은 자동으로 빠진다"와 같은 방침이다.

## 비목표

- 1D · 1W 분봉 캔들. 1D 는 현재가를 끝에 이어붙이는 처리가 따로 있어 그 규칙부터
  다시 정해야 한다.
- 1Y 캔들.
- 외부 차트 플러그인 도입.
- 캔들 패턴 판정(망치형·장악형 등).

## 접근

### 채택: 커스텀 플러그인이 캔버스에 직접 그린다

`crossMarkPlugin`(교차 지점 ▲▼)과 같은 방식이다. 저장소에 이미 캔버스에 직접
그리는 플러그인이 셋 있다 — `hLine` · `crosshair` · `crossMark`.

**기존 데이터셋은 지우지 않고 투명하게 만든다.** 이것이 설계의 핵심이다.

- **y축 범위** — `renderer.js` 주석에 남은 교훈: "정규 데이터셋이라 y축이 알아서
  범위에 넣는다. 캔버스에 직접 그리면 기울어진 선의 양 끝이 축 밖으로 나가 말없이
  잘린다(시간외 선에서 겪음)." 고가~저가 밴드 데이터셋을 투명하게 남기면 꼬리
  끝까지 축이 알아서 잡는다.
- **툴팁·호버** — `interaction: { mode: 'index', intersect: false }` 라 점 좌표가
  아니라 인덱스로 동작한다. 0번 데이터셋(종가)이 값만 갖고 있으면 툴팁과
  `onHover`(이동평균 범례)가 **지금 코드 그대로** 돈다.

그래서 캔들 모드에서 손대는 것은 색뿐이다 — 종가 라인의 `borderColor` 와 그라데이션
`backgroundColor`, 밴드의 `backgroundColor` 를 투명으로.

### 기각: floating bar 데이터셋

`data: [[low, high]]` 형태로 Chart.js 의 기본 bar 를 쓰면 축·툴팁이 공짜다. 그러나
시가 = 종가인 **도지는 높이 0 이라 사라진다**. 상세의 오늘 캔들에서 이미 몸통 최소
1px 이 필요했던 문제가 그대로 돌아온다. 거래량 bar 와 축·스택 규칙이 얽히는 것도
피하고 싶다.

### 기각: `chartjs-chart-financial`

의존성이 늘고, 번들러가 없어 `node_modules` 에서 직접 로드해야 한다. 340px 위젯에
과하다.

## 그리는 규칙

**모양** — 몸통은 시가~종가 사각형, 꼬리는 저가~고가 세로선. 몸통 최소 높이 1px
(도지가 사라지지 않게). 봉 폭은 카테고리 간격의 70%, 최소 1px · 최대 12px.

**색** — 상세의 오늘 캔들과 같은 규칙: 시가보다 종가가 높으면 `UP`(빨강), 낮으면
`DOWN`(파랑), 같으면 `--flat`. **전일 종가 대비가 아니라 시가 대비다.**

**그리는 순서** — `beforeDatasetsDraw`. 캔들이 이동평균선·추세선 **아래**에 깔려야
선이 묻히지 않는다. `crossMarkPlugin` 이 `afterDatasetsDraw`(위)인 것과 반대다.

**거래량·기준선·십자선·교차 표식** — 그대로 둔다.

## 버튼

타임프레임 줄(`#tf`) 왼쪽에 토글 하나. `renderTabs()` 가 함께 그린다.

- 캔들 모드일 때 `mode-on`(`.on` 아님) — `.on` 은 restore · period · chart-integrity 가
  "선택된 타임프레임"으로 읽으므로 토글에 쓰면 안 된다
- **1M · 3M 밖에서는 흐리게 비활성.** 이동평균 칩이 구간에 안 맞을 때 흐려지고
  `title` 로 이유를 말하는 것과 같은 패턴이다 — `1M · 3M 에서만 캔들로 그립니다`
- 누르면 `state.chartMode` 를 뒤집고 `save()` 후 `loadChart()`
- `loadChart` 의 다시 그리기 서명에 캔들 모드가 들어가야 이 호출이 실제로 다시 그린다

> 그 줄은 이미 빡빡하다. 주석에 "폭 340px 에 배지가 셋 이상 들어가면 줄이 접힌다"고
> 적혀 있다. 구현 중 브라우저로 실제 폭을 재고, 접히면 자리를 옮긴다.

## 상태

`state.chartMode` — `'candle'` 또는 `'line'`. **기본값 `'candle'`**.

저장된 설정에 이 키가 없는 기존 사용자는 초기화에서 기본값을 받는다. `maPeriods` 가
없을 때 `[5, 20, 60]` 으로 채우는 자리와 같은 곳이다 — `'candle'` 과 `'line'` 이
아닌 값이 들어 있으면 `'candle'` 로 본다.

저장 경로가 셋이라 **모두** 고쳐야 한다.

1. `renderer.js` 의 `save()` 에 `chartMode: state.chartMode` 추가
2. `main.js` 의 `state:set` **허용목록**에 `'chartMode'` 추가
3. `main.js` 의 `state:get` 반환값에 `chartMode` 추가

`tests/state-contract.mjs` 가 이 셋을 모두 검사한다.

허용목록을 빠뜨리면 `store.set` 이 호출되지 않아 **저장이 조용히 무시된다.** 앱을
껐다 켜야만 드러난다.

## 툴팁

캔들 모드에서 한 줄을 더한다 — **종가 줄 다음, `고저 A ~ B` 줄 앞**에 `시 279,000`.
지금은 종가와 고저 두 줄인데, 시가가 없으면 몸통이 왜 그 방향인지 툴팁만 보고는 알
수 없다. 세 줄이 되지만 툴팁 높이 경고(이동평균 9개면 197px)와는 무관하다.

라인 모드의 툴팁은 바뀌지 않는다.

## 데이터 경로

`loadChart` 가 `opens` 를 고가·저가와 **똑같이** 다룬다.

```js
const opens = pad(r.opens, (i) => closes[i]);
```

오늘 봉 실시간 동기화에도 시가를 포함한다. 이미 `candleOf(q)` 가 세션 규칙과 클램프를
거친 `open` 을 준다 — 지금 종가·고가·저가만 쓰고 있어 한 줄 더하면 된다.

`drawChart(arg)` 는 `opens = []` 를 받는다.

## 순수 함수와 테스트

픽셀 좌표는 Chart.js 의 `scales.y.getPixelForValue()` 가 준다. 그래서 따로 뺄 만한
순수 계산은 둘뿐이다. `indicators.js` 에 넣고 `tests/candle.mjs` 에서 검증한다.

| 함수 | 하는 일 |
|---|---|
| `candleWidth(spacing)` | 카테고리 간격 → 몸통 폭. 70%, 최소 1 · 최대 12, 정수 |
| `candleBody(yOpen, yClose)` | 두 y픽셀 → `{ top, h }`. 최소 높이 1px |

검증할 것: 도지(`yOpen === yClose` → h = 1), 위아래 뒤집힘(시가가 아래일 때도
top 이 위), 폭 상·하한(1봉일 때, 243봉일 때), 소수 좌표.

나머지(색, 투명 처리, 그리는 순서, 버튼 배치)는 화면이라 사용자가 직접 본다.

## 위험

| 위험 | 완화 |
|---|---|
| `chartMode` 가 저장되지 않는다 | `main.js` 허용목록을 반드시 함께 고친다. 앱 재실행으로만 드러나므로 사용자 확인 항목에 넣는다 |
| 타임프레임 줄이 접힌다 | 구현 중 브라우저로 실제 폭을 잰다. 접히면 자리를 옮긴다 |
| 3M 에서 4.3px 캔들이 뭉개진다 | 폭 하한 1px 과 70% 규칙으로 최소한 몸통·꼬리가 구분되게 한다. 실제로 보고 판단 — 못 쓸 정도면 3M 을 범위에서 뺀다 |
| 캔들이 이동평균선을 덮는다 | `beforeDatasetsDraw` 로 아래에 깐다 |
| y축이 꼬리를 자른다 | 밴드 데이터셋을 투명하게 **남긴다**. 지우면 안 된다 |
