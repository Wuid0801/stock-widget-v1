# 차트 끌어서 확대 — 설계

2026-09-28

## 왜

3M · 1Y 차트에서 **과거 특정 구간**을 자세히 볼 방법이 없다. 폭 약 280px 에 3M 은 62봉(봉 하나 약 4.5px), 1Y 는 243봉(1.2px)이 들어간다. 최근 구간은 1M · 3M 버튼으로 볼 수 있지만, 1Y 의 몇 달 전 한 구간은 볼 수 없다.

## 사용자가 정한 것

| 질문 | 결정 |
|---|---|
| 확대 방식 | 끌어서 구간 선택 (휠 줌 · 구간 슬라이더 아님) |
| 확대해서 봉이 넓어지면 | 캔들로 그린다 — 캔들 기준을 "기간"에서 "보이는 봉 수"로 |
| 허용 기간 | 3M · 1Y 만 |
| 확대 중 추세선 | 숨긴다 |

## ① 조작

**고르기**
- 3M · 1Y 차트 위에서 마우스를 누른 채 좌우로 끌면 반투명 상자가 따라온다. 놓으면 그 구간이 차트 전체로 펼쳐진다.
- 끄는 동안 툴팁 · 십자선은 계속 보인다 — 어느 날짜를 고르는지 알 수 있게.
- **5봉 미만**으로 끌면 확대하지 않는다. 클릭 · 손떨림과 구분하고, 취소하고 싶을 때 도로 좁게 끌면 된다.
- 확대된 상태에서 다시 끌면 그 안에서 한 번 더 확대된다.
- 끌다가 차트 밖으로 나가면 차트 끝에서 멈춘다. 놓는 곳이 차트 밖이어도 확대된다(창 밖에서 놓는 경우 포함 — `mouseup` 은 `window` 에서 받는다).

**되돌리기**
- 차트 **더블클릭**, 또는 확대 중에만 보이는 **`전체`** 버튼. `전체` 는 차트 안 왼쪽 위, 캔들/라인 아이콘(`#chartMode`) 오른쪽에 둔다.
- 두 버튼은 한 묶음(`.chartctl`, 차트 왼쪽 위에 절대 위치 · 가로 flex)에 넣는다. 확대했어도 보이는 봉이 70개를 넘으면 캔들 아이콘은 숨는데, 그때 `전체` 가 빈자리 없이 왼쪽으로 붙게 하려는 것이다. 지금 `#chartMode` 에 걸린 절대 위치는 이 묶음으로 옮긴다.

**실수로 확대되지 않게**
- 마우스가 지나가거나 휠을 굴리는 것만으로는 절대 확대되지 않는다. 항상 떠 있는 창이라 마우스가 차트 위를 자주 지나가기 때문이다.
- `#chartMode` · `전체` 버튼 위에서 누른 것은 끌기로 치지 않는다(버튼은 캔버스의 형제 요소라 캔버스가 이벤트를 받지 않는다).
- 왼쪽 버튼으로 누른 것만 끌기로 친다.

## ② 그리기

**축**
- x축은 `scales.x.min` / `max` 에 봉 번호를 넣어 고른 구간만 보인다.
- **y축은 저절로 그 구간에 맞춰진다.** Chart.js 4.5.1 의 `DatasetController.getMinMax` 가 다른 축의 사용자 범위(`getUserBounds`) 밖의 점을 건너뛰기 때문이다(`node_modules/chart.js/dist/chart.js` 에서 확인). 투명하게 남겨 둔 고가~저가 밴드가 여전히 꼬리까지 y 범위를 잡는다.
- 거래량 축(`yVol`)의 최댓값은 지금 전체 기간 최대 거래량의 4배로 고정돼 있다. 확대 중에는 **보이는 구간의 최대 거래량**으로 계산한다. 그대로 두면 막대가 납작해진다.

**캔들**
- 기준: 캔들 모드이고, 일봉 기간이고, **보이는 봉이 70개 이하**면 캔들로 그린다.
- 70 의 근거: 3M 이 62~66봉이다. 지금 3M 캔들과 같은 굵기 이상일 때만 캔들로 그린다.
- 확대하지 않은 결과는 지금과 같다 — 1M(약 22봉) · 3M 캔들, 1Y(243봉) 라인, 1D · 1W 라인. 1Y 를 70봉 이하로 좁히면 캔들이 된다.
- 캔들/라인 아이콘(`#chartMode`)도 같은 기준으로 나타난다.
- `candlePlugin` 의 봉 간격은 지금 `sx.width / opens.length` 다. 확대하면 보이는 봉 수로 나눠야 한다 — 이웃한 두 봉의 픽셀 거리(`getPixelForValue(i+1) − getPixelForValue(i)`)를 쓴다. 구간 밖 봉은 `ctx.clip()` 이 자른다.

**함께 그리는 것**
- 이동평균선, ▲▼ 교차 표식, 평단 점선. 구간 밖은 잘린다. ▲▼ 는 과거 구간을 볼 때 오히려 쓸모가 크다.
- `crossMarkPlugin` 과 `candlePlugin` 은 이미 `ctx.clip()` 으로 차트 영역에 가둔다. `hLinePlugin` 은 범위 밖 값을 생략한다.

**숨기는 것 — 지지 · 저항 추세선**
- 추세선은 "지금"을 말하는 선이다(최근 5봉을 빼고 만들고 오늘 값 · 돌파를 계산한다).
- 과거 구간을 확대하면 그 구간 가격에서 멀리 떨어진 선이 정규 데이터셋이라 y축을 다시 벌린다. 확대 효과를 깎는다.

**그대로인 것**
- 배지(RSI · 기간 수익률 · 골든/데드 · 돌파 · 수렴) — 전체 기간과 지금 기준.
- 툴팁 · 이동평균 범례 hover — 인덱스 기반이라 그대로 동작한다.

**선택 상자**
- 끄는 동안 반투명 사각형을 그리는 플러그인(`zoomBoxPlugin`)을 둔다. 끌기 상태는 모듈 변수에 두고 플러그인이 매번 읽는다.

## ③ 상태와 갱신

**확대 구간은 날짜로 기억한다** — `zoom = { start, end }` (봉 시각, ms). 봉 번호가 아니다.
- 30초마다 차트를 새로 그리고, 다음 날엔 봉이 하나 늘어 번호가 밀린다. 그릴 때마다 날짜를 지금 데이터의 봉 번호로 바꾼다.
- **비교는 시각이 아니라 UTC 날짜로 한다** — `maFor` 와 같은 규칙(`Math.floor(t / 86400000)`). 장중 마지막 봉의 시각은 마지막 체결 시각이라 갱신마다 바뀐다. 시각으로 비교하면 마지막 봉을 넣어 확대한 뒤 다음 갱신에서 그 봉이 구간 밖으로 밀려난다.
- 바꾼 결과가 5봉 미만이면 전체 보기로 돌아간다.

**끄는 도중에 갱신이 와도 끊기지 않는다**
- 마우스 이벤트는 차트 인스턴스가 아니라 캔버스 요소(`#chart`)에 한 번만 붙인다. `drawChart` 는 `chart.destroy()` 후 같은 캔버스에 새 차트를 만들므로 캔버스와 끌기 상태가 살아남는다.

**언제 풀리나**

| 동작 | 확대 |
|---|---|
| 기간 버튼 바꾸기 | 풀림 |
| 다른 종목 선택 | 풀림 |
| 캔들/라인 전환 · 테마 변경 · 30초 자동 갱신 · ↻ | 유지 |
| 앱 재실행 | 풀림 (저장하지 않는다 — `save()` · `state:set` · `state:get` 은 건드리지 않는다) |

**다시 그리기**
- 확대 · 되돌리기는 네트워크 요청 없이 `drawChart(lastChart)` 로 다시 그린다(테마 변경과 같은 경로).
- `loadChart` 의 다시 그리기 서명은 지금 `candleMode(state.timeframe, state.chartMode)` 를 넣는다. 캔들 판단이 봉 수로 바뀌므로 서명에는 `state.chartMode` 와 확대 구간을 직접 넣는다. 캔들 토글 때 "서명에 모드가 빠져 다시 안 그려지던" 버그를 되풀이하지 않기 위해서다.

## ④ 코드 구조

**`indicators.js` — 순수 함수 (화면 없이 테스트)**

| 이름 | 하는 일 |
|---|---|
| `ZOOM_TF` | `Set(['3M', '1Y'])` |
| `ZOOM_MIN_BARS` | `5` — 클릭 · 손떨림과 구분 |
| `CANDLE_MAX_BARS` | `70` — 3M(62~66봉)과 같은 굵기 이상 |
| `dragToRange(a, b)` | 끈 두 봉 번호를 `{ from, to }` 로 정렬. 5봉 미만이면 `null` |
| `zoomRange(times, start, end)` | 날짜 구간 → 지금 데이터의 `{ from, to }`. UTC 날짜로 비교. 5봉 미만이면 `null` |
| `candleMode(bars, daily, chartMode)` | `chartMode !== 'line' && daily && bars <= CANDLE_MAX_BARS` |

`CANDLE_TF` 는 없앤다. `candleMode` 의 인자가 바뀌므로 부르는 곳(`drawChart` · `loadChart` 서명 · `renderChartMode`)을 모두 고친다.

**`renderer.js`**
- 모듈 변수 `zoom`(날짜 구간 또는 `null`)과 끌기 상태.
- 캔버스에 `mousedown` · `mousemove`, `window` 에 `mouseup`, 캔버스에 `dblclick`. 픽셀 → 봉 번호는 `chart.scales.x.getValueForPixel(px)` 를 반올림하고 `0 ~ n−1` 로 조인다.
- `zoomBoxPlugin` 추가.
- `drawChart`: `zoomRange` 로 x 구간을 정하고, 보이는 봉 수로 캔들 판단, `yVol` 최댓값, 추세선 숨김.
- 기간 버튼 · `select()` 에서 `zoom = null`.
- `renderChartMode` 는 보이는 봉 수 기준으로 아이콘을 보인다. `전체` 버튼은 확대 중에만 보인다.

**`index.html`**
- `.chartbox` 안의 `#chartMode` 를 `<span class="chartctl">` 로 감싸고, 그 안에 `<button id="zoomReset" type="button" hidden>전체</button>` 를 더한다. 스타일은 `#chartMode` 와 같은 계열.

## 테스트

사용자 지시: 문법 검사(`node --check`)와 스위트까지. 끌어서 확대하는 실제 동작은 사용자가 화면에서 본다.

- 새 스위트 `tests/zoom.mjs`
  - `dragToRange`: 오른쪽→왼쪽으로 끌어도 `from < to`, 4봉은 `null`, 5봉은 통과
  - `zoomRange`: 날짜 구간 → 봉 번호, 새 봉이 뒤에 붙어도 같은 구간, 마지막 봉 시각이 몇 초 바뀌어도 그 봉이 구간에 남는다, 데이터에 없는 구간이면 `null`, 5봉 미만이면 `null`
- `tests/candle.mjs`: 바뀐 `candleMode` — 확대하지 않은 1M(22) · 3M(62) · 1Y(243) · 분봉 결과가 지금과 같다, 1Y 를 70봉으로 좁히면 캔들, 71봉이면 라인, `line` 모드면 늘 라인
- CI 목록에 `zoom` 추가 — `.github/workflows/test.yml` 과 `tests/run.mjs` 의 `ORDER`, 스위트 수 8 → 9 (워크플로 주석 · README · 개발 문서)

## 하지 않는 것

- 휠 줌, 끌어서 좌우 이동(팬), 구간 슬라이더
- 1D · 1W · 1M 확대
- 확대 구간 저장
- 확대 구간의 수익률 배지 (기간 수익률 배지는 전체 기간 그대로)
