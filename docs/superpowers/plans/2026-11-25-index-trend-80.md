# 지수 80일선 추세 표시 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 지수 줄의 코스피 · 코스닥 · 나스닥 · S&P 500 옆에 80일선 기준 추세 상태(상승 · 하락 · 상승전환 · 하락전환)와 며칠째인지 보인다.

**Architecture:** `indicators.js` 에 순수 함수 `maTrend` 하나. 렌더러가 이미 받는 5년 일봉(`dailyCache`)의 확정 봉(마지막 봉 뺌)으로 `renderIndices` 에서 계산해 그린다. 요청은 늘지 않는다.

**Tech Stack:** Electron 렌더러 전역 스크립트, 순수 함수는 `indicators.js`(Node 테스트는 CommonJS import).

**Spec:** `docs/superpowers/specs/2026-11-25-index-trend-80-design.md`

- 판정 값: 80일 단순이동평균, 기울기는 5봉 전 80일선과 비교. 종가와 같으면 "아래", 5봉 전과 같으면 "내림".

## Review Focus

1. 일봉이 85봉(80 + 5)보다 적은 지수 · 아직 일봉을 못 받은 첫 실행 — 글자 없이 지금 지수 줄 그대로여야 한다.
2. 장중 — 마지막 봉(움직이는 오늘 값)을 빼므로 30초 갱신마다 상태가 바뀌지 않아야 한다. 장이 닫힌 것이 확실하면(`quotes[].isTrading === false`) 마지막 봉까지 쓴다(Ruling, 스펙 갱신).
3. 대상 아닌 지수(나스닥 선물 · 원/달러 등) — 글자가 붙지 않아야 한다.
4. 일봉 받기 실패로 `dailyCache` 가 낡았을 때(`stale`) — 있던 값으로 그대로 보인다(따로 처리 없음).
5. 좁은 위젯 폭 — 두 지수 + 글자가 한 줄을 넘는지는 사용자가 화면에서 본다.

### Task 1: `maTrend` 순수 함수

**Files:**
- Modify: `indicators.js` (`trendFollow` 바로 아래, `module.exports` 에 추가)
- Test: `tests/techniques.mjs` (추세 추종 블록 다음, import 에 `maTrend` 추가) — 커밋 때

**Interfaces:**
- Produces: `maTrend(closes: number[], period = 80, lag = 5) → { state: 'up'|'down'|'upTry'|'downTry', days: number, close: number, ma: number, maLag: number } | null`
  - `up`: 종가 > ma 이고 ma > maLag · `down`: 종가 ≤ ma 이고 ma ≤ maLag · `upTry`: 종가 > ma, ma ≤ maLag · `downTry`: 종가 ≤ ma, ma > maLag
  - `days`: 마지막 봉부터 거슬러 같은 state 가 이어진 봉 수(마지막 봉 포함, maLag 를 셀 수 있는 봉까지만)
  - `closes` 가 없거나 길이 < period + lag 이면 null

- [ ] **Step 1: 구현** — `sma(closes, period)` 를 재사용, `trendFollow` 처럼 뒤에서부터 센다.
- [ ] **Step 2: 확인** — `node --check indicators.js`, scratch 에서 `require('../indicators.js').maTrend` 로 아래 테스트 값을 한 번 찍어 본다.
- [ ] **Step 3 (커밋 때): 테스트** — `tests/techniques.mjs`:
  - `오르기만 하면 up` — `Array.from({length: 120}, (_, i) => 100 + i)` → `state === 'up'`, `days === 120 - 85 + 1` (36)
  - `내리기만 하면 down` — 위 배열을 뒤집은 것 → `state === 'down'`
  - `오르다 급락하면 downTry` — 오름 120봉 + 100 을 3봉 → `state === 'downTry' && days === 3`
  - `내리다 80일선만 넘으면 upTry` — 내림 120봉(`219 - i`) + 150 을 2봉 → `state === 'upTry' && days === 2` (1000 처럼 크게 뛰면 5봉 사이 80일선도 올라 `up` 이 된다)
  - `85봉 미만이면 null` — 84봉 → null, `maTrend(null) === null`
  - `평평하면 down` — `Array(90).fill(7)` → `state === 'down'`
  - `ma · maLag 값` — 오름 배열에서 `ma === sma(a, 80)[119]`, `maLag === sma(a, 80)[114]`

- [ ] **Step 1: 구현** — 확정 봉만: `closes.slice(0, -1)` · `times.slice(0, -1)`. 글자와 색:

  | state | 글자 | 색 |

  80일선 추세 — {상승 추세 | 하락 추세 | 상승 전환 시도 | 하락 전환 시도}

  지금 상태일 뿐 다음 방향을 맞히는 신호가 아님
